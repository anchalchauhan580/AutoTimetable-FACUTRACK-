#  AutoTimetable (FACUTRACK)

AutoTimetable (FACUTRACK) is a full-stack timetable management system with role-based access for Students, Faculty, HOD, and Admin.

##  Tech Stack
- React (Vite)
- Express.js
- SQLite
- JWT Authentication
- Socket.IO

## 📂 Project Setup

### Backend
```bash
cd server
npm install
npm start
```

### Frontend
```bash
cd client
npm install
npm run dev
```
